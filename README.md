# Guanduo Chen's Homepage

Personal homepage of Guanduo Chen, built with Jekyll and hosted on GitHub Pages.

## Local development

```bash
bundle install
bundle exec jekyll serve --config _config.yml,_config.dev.yml
```

Then visit http://localhost:4000.

## Content

- `_pages/about.md` — the homepage (everything lives here)
- `_config.yml` — site and author settings
- `images/profile.jpeg` — avatar
